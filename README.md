Grocery Store Website 🛒

A modern and fully responsive grocery e-commerce website built using React and Tailwind CSS. This project showcases different grocery categories like Fruits, Vegetables, Dairy, Eggs, Seafood, and more with product filtering functionality and a clean UI design.
